# DESIGN SYSTEM & BRAND GUIDELINES - SI UKRI

Dokumen acuan standar desain visual untuk website **Program Studi Sistem Informasi Universitas Kebangsaan Republik Indonesia (SI-UKRI)**.

---

## 1. Palette Warna Resmi (Berbasis Logo Prodi)

Sistem warna diselaraskan secara presisi dengan identitas visual **Logo Resmi Prodi Sistem Informasi UKRI**:

| Kategori Token | Nama Token Tailwind | Nilai HEX | Deskripsi Visual & Penggunaan |
| :--- | :--- | :--- | :--- |
| **Primary Green** | `brand-teal` | `#0A6B39` | Warna hijau zamrud utama logo ("INFORMASI" & lambang "S"). Digunakan untuk tombol utama, link, badge, dan aksen aktif. |
| **Dark Green Navy** | `brand-navy` | `#0C2B1C` | Warna hijau hutan pekat/navy dasar header, navbar, dan hero section. |
| **Ultra Dark Navy** | `brand-darknavy` | `#051B11` | Warna topbar dan footer background. |
| **Accent Red** | `brand-red` | `#EF3829` | Warna merah oranye cerah logo ("SISTEM"). Digunakan untuk tombol PMB, badge highlight, dan notifikasi penting. |
| **Academic Gold** | `brand-gold` | `#EAB308` | Warna emas lambang UKRI (di dalam huruf 'O'). Digunakan untuk akreditasi "A", bintang prestasi, dan aksen header. |
| **Light Tint BG** | `brand-lightbg` | `#F4FAF6` | Latar belakang halaman publik dengan sentuhan soft-tint hijau segar. |

---

## 2. Tipografi Resmi
- **Heading / Judul**: `Poppins` (Bold, SemiBold, ExtraBold)
- **Body Text / Paragraf**: `Inter` (Regular, Medium)

---

## 3. Komponen Utama & Penggunaan Token
- **Header & Navigation Bar**: `bg-brand-navy`, aksen `text-brand-gold`, tombol `bg-brand-red`.
- **Hero Banner**: Gradien `from-brand-navy via-brand-darknavy to-slate-950`.
- **Admin Panel Filament**: Color primary `#0A6B39` (Emerald Green) dan danger `#EF3829` (Logo Red).
